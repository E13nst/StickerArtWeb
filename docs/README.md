# Docs — agent-readable project knowledge

Эта папка предназначена для устойчивого контекста, который должен быть доступен людям и агентам из git.

## Что хранить здесь

- Архитектурные решения и карты слоёв.
- Продуктовые инварианты и критичные user journeys.
- Надёжность, failure modes, наблюдаемость, QA-планы.
- Техдолг, который повторяется в ревью и должен стать правилом, lint или тестом.

## Что не хранить здесь

- Секреты, токены, приватные ключи, `.env`.
- Личные заметки. Для них используйте `*.local.md` — они игнорируются git.
- Сырые планы без ревью: план в репозитории считается входом для будущих агентов, поэтому его нужно проверять как код.

## Принцип

`AGENTS.md` остаётся короткой картой. Подробности, которые не должны вытеснять текущую задачу из контекста, живут здесь или в специализированных файлах `.cursor/`.
